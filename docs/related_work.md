# Related work and open-source context

This repository is an original implementation. The projects below are useful references because they show how current AIED and learning-analytics work connects educational questions, data, software, and evaluation. They are not dependencies and this repository does not claim to reproduce their results.

- **FLoRA Engine**: analytics and AI support for self-regulated learning: https://github.com/Xinyu-Li/FLoRA
- **Serial learning-analytics dashboards**: Moodle dashboards designed to support self-regulated learning: https://github.com/CATALPAresearch/format_serial1
- **LASER Institute**: open materials and reproducible workflows for learning analytics: https://github.com/laser-institute

The most useful comparison is methodological: what decision the system supports, what evidence it uses, how uncertainty is handled, and how the human role is designed.
